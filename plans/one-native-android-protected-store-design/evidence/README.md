# SDK proof receipts

These are isolated public Android SDK probes, not an Android One implementation.
The main plan names the assigned gate and complete protocol.

- `producer.json` pins the One contract and first probe source/artifact.
- `producer-final.json` pins the SDK, emulator build, source boundaries and actual
  installed main/no-permission APK hashes. Installed bytes were pulled back and
  matched to the built APKs. APK copies are preserved in the worker handoff folder.
- `events-final.jsonl` contains all main-probe events, including earlier failed
  attempts. `events-v1.jsonl` and `events-v2.jsonl` are earlier checkpoints.
  The source boundary epochs select archived v1/v2 Java or final probe Java.
- `commands.jsonl` retains full actual argv, return codes, stdout/stderr and UI
  XML for the recorded controller calls. Duplicate standalone XML files were
  removed only after matching their complete contents to these command receipts.
- `fingerprint-enrollment-state.txt` is the count-one baseline;
  `fingerprint-after-enrollment.txt` is the count-two positive control.
- `events-no-permission.jsonl` is a different APK/UID with biometric permission
  omitted. It is not a pretend failure or a toggled runtime-permission result.
- `verification.json` is generated by `../probe/verify-evidence.py` and asserts
  actual successes, error causes, record/key identity and producer hashes.
- `readonly-descriptors.txt` shows writable temporary emulator overlays and
  read-only persistent AVD backing images. `process-identity.txt` identifies
  the exact owned process, AVD, port and read-only/no-save flags.

The isolated probe activity is exported and debuggable for shell automation.
It is review evidence only and must never be shipped. The test values and PIN
are synthetic. Final One host serialization, create/delete crash transactions,
error payloads, permissions and Nitro binding gates remain implementation work
for the original source owner after design approval.
