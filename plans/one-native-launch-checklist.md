# One native: launch checklist

Nate (2026-10-05, voice, relayed by native-lead p63991): "get One Native to basically launch ready."

Launch ready means: one package builds a first-class app on iOS, Android and
web; every public native export has runtime proof on each platform it runs
on; every shipped API has a docs page; v2-beta CI is green. The ranked queue
and staffing live in `one-native-launch.md`; this file is the go/no-go list.
Tick a box only with a receipt (SHA, run id or evidence path).

  Native Tests. RAN 2026-10-05: `Checks and Tests` failed on `62e0f7a4d`;
  iOS Native Tests passed on the same SHA. Owner: v2-beta CI owner (p61056).

  workspace link.

## 2. iOS runtime coverage (owner r60572)

Source of truth: `tests/native-features/COVERAGE.md`, generated by
`packages/one/src/nativeCoverage.test.ts`. 96 of 99 `One.iOS` exports have a
suite. Remaining iOS holes, in launch order:

- [ ] `One.UI.TextInput`: suite `ui-text-input` (defaultValue, typing,
  maxLength, ref focus/blur/clear/isFocused, focus events, submit,
  NativeState value, secure entry, read-only). Needs its iPhone 16 run.
- [ ] `One.UI.Image`: suite `ui-image` (bundled asset, remote size, source
  change, onError, recycle). Needs its iPhone 16 run.
- [ ] `One.openURL`, `openShare`, `openSettings`: one suite, system sheet and
  Settings handoff observed.
- [ ] `One.UI.Icon`: fixture and suite (SF Symbol element, semantic role color).
- [ ] `One.UI.Blur`, `Mask`, `EdgeFade`, `sampleCurve`, `serializeCurve`: turn
  the effects capture script into a suite with a pixel assertion.
- [ ] adaptive: `ReservedRegions`, `useReservedRegions(Ready)`, `useSizeClass`,
  `getSizeClass`, `useHinge`, `getHinge`, `onHingeChange`,
  `useWindowSegments`, `useSpanning`: one suite over the existing fixture.
- [ ] `useNetworkState`: add to the network suite.
- [ ] `One.iOS.ZoomTransitionEnabler`, `ZoomTransitionAlignmentRectDetector`:
  extend the zoom e2e.
- [ ] `One.Widgets`, `LiveActivities`, `One.iOS.WidgetUI`: need a widget

- [ ] `One.UI.PictureInPicture`: device run (simulators report no PiP).
- [ ] ArrangementView on iOS 27.1: blocked on a pool runtime that supports

## 3. Expo UI parity, iOS

Per `one-native-coverage.md` (export diff against `@expo/ui` 58 canary), every
`@expo/ui/swift-ui` component and modifier has a One counterpart except:

- [ ] `Chart` with mark children. New public API: waits for Nate on a branch.
- [ ] `withAnimation` imperative transaction. New public API: waits for Nate.
- [ ] `AccessoryWidgetBackground`, `widgetURL`, `widgetAccentedRenderingMode`,
  `activityBackgroundTint`: widget-only, belong with `WidgetUI`.

These are product choices. Launch does not block on them unless Nate says so.
