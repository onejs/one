# Getting started

Install Bun 1.4.2 and Node 24.16 or newer. Run `bun install` and `bun dev`, then
open http://localhost:4200. Choose Try the demo and Login as Demo User.

Run `bun check` to check types and lint. With Xcode and CocoaPods installed,
run `bun prebuild:native --platform ios` and `bun ios` while the dev server is
running. Android requires Android Studio and a JDK.
