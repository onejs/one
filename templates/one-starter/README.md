# One starter

A shared web and native app with One v2 beta, Tamagui v3 beta, Better Auth,
Drizzle, and Orez Lite over SQLite. The app includes a feed, posts, comments,
profiles, and account settings.

## Run

Install Bun 1.4.2 and Node 24.16 or newer, then run:

```sh
bun install
bun dev
```

Open http://localhost:4200 and choose **Try the demo**, then **Login as Demo User**.
One starts web, regular Metro, and the local SQLite sync host together.
`PORT_OFFSET=100 bun dev` moves the service ports together. Local state lives
in `.orez/`; development environment values are generated by `env.ts`.

## Native

With Xcode and CocoaPods installed, run `bun prebuild:native --platform ios`
then `bun ios` while `bun dev` is running. Android uses `bun android` with
Android Studio and a JDK. Native names, identifiers, and linking scheme derive
from the scaffolded package name in `appIdentity.ts`.

Native storage uses One. Auth uses session cookies on web and a persisted
bearer token on native. Both use the same SQLite application database and sync
permissions.

## Develop

Run `bun check` for types and lint. `bun generate` regenerates database
migrations and Zero models. `bun build` emits the Cloudflare worker and web
assets. Configure your deployment's SQLite Durable Object, Orez Lite sync host,
auth secret, and upload storage before deploying that output. The local demo
fixture is seeded only for development.

- `app/`: routes and API handlers.
- `auth/`: session transport and authentication.
- `data/`: models, mutations, permissions, queries, and Zero client/server bindings.
- `database/`: SQLite schema, migrations, and seed data.
- `features/` and `interface/`: application behavior and shared components.
- `tamagui/`: themes, fonts, and platform animations.

Replace the development auth secret for deployment. Email OTP uses [Resend](https://resend.com/docs/api-reference/emails/send-email)
in production: set `RESEND_API_KEY` and `AUTH_EMAIL_FROM`; the demo uses email and password. Development uploads are saved under `.orez/uploads` and served by One.
Set R2 credentials and the public bucket URL in `env.ts` for production uploads.
