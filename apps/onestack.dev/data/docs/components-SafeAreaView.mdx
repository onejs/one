`SafeAreaView` renders content within the safe area boundaries of a device, avoiding notches, status bars, and home indicators.

`One.UI.SafeArea` is One's shared safe area API. It uses One's native host on iOS and
Android and CSS environment insets on web, with no separate safe area package in your app.

## Usage

```tsx fileName=app/_layout.tsx
import { One, Slot } from 'one'

export default function Layout() {
  return (
    <One.UI.SafeArea.View style={{ flex: 1 }}>
      <Slot />
    </One.UI.SafeArea.View>
  )
}
```

## Props

`One.UI.SafeArea.View` extends all standard `View` props and adds:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `mode` | `'padding' \| 'margin'` | `'padding'` | How to apply the safe area insets |
| `edges` | `Edge[]` | All edges | Which edges to apply insets to |

## Examples

### Apply to Specific Edges

```tsx
import { One } from 'one'

// Only apply to top (useful for screens with bottom tabs)
<One.UI.SafeArea.View edges={['top']}>
  {/* Content */}
</One.UI.SafeArea.View>

// Only apply to top and bottom
<One.UI.SafeArea.View edges={['top', 'bottom']}>
  {/* Content */}
</One.UI.SafeArea.View>
```

### Use Margin Instead of Padding

```tsx
<One.UI.SafeArea.View mode="margin" style={{ flex: 1 }}>
  {/* Content */}
</One.UI.SafeArea.View>
```

## Hooks

### useSafeAreaInsets

Get the current safe area insets for custom layouts:

```tsx
import { One } from 'one'

function MyComponent() {
  const insets = One.UI.SafeArea.useInsets()

  return (
    <View style={{ paddingTop: insets.top, paddingBottom: insets.bottom }}>
      {/* Content */}
    </View>
  )
}
```

Returns `{ top, right, bottom, left }` in pixels.

## Platform Behavior

- **Web**: Reads CSS `env(safe-area-inset-*)` values.
- **iOS**: Reads native safe area APIs for the status bar, notch or Dynamic Island, and home indicator.
- **Android**: Reads native window insets for status bars, navigation bars, and display cutouts.

One automatically sets up `SafeAreaProvider` - no additional setup needed.
