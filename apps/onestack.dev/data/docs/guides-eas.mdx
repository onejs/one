---
title: Build and Deliver Native Apps with EAS
---

[Expo Application Services (EAS)](https://expo.dev/eas) is a service that helps you build and deploy your React Native apps without the hassle of managing code signing, provisioning profiles, and other complexities of native development by yourself.

Native apps built with One can be deployed using EAS as existing React Native projects. Generate the native projects with `one prebuild` before configuring EAS.

After the initial EAS setup (`eas build:configure`), you will be able to run `eas build` to build your app, and `eas submit` to submit it to the App Store or Google Play directly in your One project.

For more instructions, see the ["Create your first build" guide in the EAS documentation](https://docs.expo.dev/build/setup/).

<Notice>
  Configure distribution identifiers under `native.app` in `vite.config.ts`. Generally, following the instructions in the terminal and the [EAS documentation](https://docs.expo.dev/build/setup/) should be sufficient to resolve most issues.
  <br /><br />
  A common type of error you'll probably see in an EAS build is:

```
The engine "node" is incompatible with this module. Expected version "^20.15.0". Got "18.18.0"
```

This is because EAS defaults to a relatively old version of Node.js. To fix this, you can modify your `eas.json` and [specify the version of Node.js](https://docs.expo.dev/build/eas-json/#selecting-build-tool-versions) like this:

```json
{
  /* ... */
  "build": {
    "shared": {
      "node": "20.15.0"
    },
    "development": {
      "extends": "shared"
      /* ... */
    },
    "preview": {
      "extends": "shared"
      /* ... */
    },
    "production": {
      "extends": "shared"
      /* ... */
    }
  }
  /* ... */
}
```

</Notice>

## Setup Your One App for EAS

EAS Build supports existing React Native projects without the Expo package. One generates those projects directly, so no One Expo config plugin is involved.

1. Configure `native.app` in `vite.config.ts` with the app name, iOS bundle ID, and Android application ID.

2. Install `@react-native-community/template` as a development dependency and run `one prebuild`.

3. Add a `react-native.config.cjs` to your project root with the following content:

   ```js
   module.exports = {
     // use One's bundle commands during native builds
     commands: [...require('one/react-native-commands')],
   }
   ```

4. Add a `postinstall` script to your `package.json` that runs `one patch` so dependency patches are present on the build worker:

   ```json
   {
     "scripts": {
       "postinstall": "one patch"
     }
   }
   ```

5. Run `eas build:configure`, then build the checked-in iOS and Android projects as an existing React Native app.
