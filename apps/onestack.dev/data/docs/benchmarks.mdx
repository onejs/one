The runtime and Bluesky comparisons use each engine's native Promise.
Background CPU activity occurred during measurement; all samples are retained.
All measurements use simulators and do not establish iPhone performance.

## Runtime

Ten samples per engine, from ten alternating pairs in one batch. Host media
analysis was paused; other background CPU activity was logged. These are exploratory measurements of
simulator behavior on this Mac. All samples are retained. Times are medians in
milliseconds; brackets contain the 25th and 75th percentiles. Lower is better.

## Bluesky: captured app measurements

These five alternating pairs use the updated native Promise setup. Bun reached
the recorded thread's final React commit sooner; Hermes returned from settings
to the home feed sooner and used less process memory.

The runs used an iPhone 17 Pro simulator on the same M2 MacBook Air. Background
CPU activity persisted despite quiet admission. All samples are retained;
these exploratory simulator results do not establish iPhone performance.

### Bluesky method

Measured on 14 November 2026 using RN 0.81.5 / Expo 54 with the new architecture.
Both variants reuse the saved native app and captured bundle. The prepared text
retains each engine's native Promise. Bun engine 0.1.3 uses ahead-of-time
compilation with JIT and WebAssembly disabled; Hermes uses optimized bytecode.
The adapter and embed script come from One/vxrn 2.0.0-0.canary.1794703544061,
source [65cba9135](https://github.com/onejs/one/commit/65cba91353f3b5faf4aed6692a832c3a039bd8cc).

Five alternating Hermes/Bun pairs ran in three batches, in logical pair order
0, 1, 4, 2, 3. Each launch started a new process. OS caches and signed-in app
data stayed warm; the saved container was restored for each launch. Native
permission prompts were dismissed before the series. Every launch completed
all eighteen actions and retained native Promise identity at all nineteen phases.
Stored responses and images replaced live network responses. Separate replay
logs for all ten launches contain no misses.

The upstream [Bluesky source](https://github.com/bluesky-social/social-app/tree/f3faaa90c74395517538234ce1b6bcb14b864e66)
required the same dependency ports on both engines: MMKV 3.3.3, paste input
2.0.1, UITextView 2.7.1 and a Fabric sheet touch handler. Both variants share
these native changes. The downloadable measurements record source and tool hashes.

## A 10,000-item feed

A separate synthetic test uses LegendList 3.3.10 and 58 saved posts with recorded
images, repeated with distinct keys to make 10,000 rows. Both processes are
capped at 25% of one CPU core. Speeds rise from 400 to 800, 1,600, 3,200 and
6,400 points per second, with five seconds at each speed.

The list receives programmatic scroll commands on JavaScript animation frames,
using a shared wall-clock position. These are not touch gestures. The video
runs at normal speed, without aligning individual stages after capture.

## Microbenchmark method

Measured on 14 November 2026.

- iPhone 17 Pro simulator, iOS 27.0, on an Apple M2 MacBook Air with 24 GB RAM.
- The saved production OneBench entry and native executable are reused. The
  captured React Native Promise setup is replaced with a no-op before preparing
  both variants. Native Promise identity is asserted on every BENCH log.
- Hermes runs optimized bytecode. Bun engine 0.1.3 uses ahead-of-time compilation
  with JIT and WebAssembly disabled at simulator launch. Its compiler and runtime
  match; the embed script comes from One/vxrn 2.0.0-0.canary.1794703544061.
  The native adapter is retained from the captured OneBench executable.
- A prior successful smoke per engine preceded ten alternating pairs in one batch:
  Hermes, Bun, Hermes, Bun. Each launch starts a new process; OS caches remain warm.
  Both variants reuse one bundle ID, so the selected variant is installed at each
  engine switch. There is no added cooldown between launches.
- The same prepared JavaScript, native UI, inputs and workload order are used on
  both engines. Source and tool hashes accompany the downloadable results.
- Quiet admission covered all ten pairs. Host media analysis processes were
  journaled and paused before and after the batch. Git, agent and simulator
  background activity was still logged. All twenty launches reported nominal
  thermal state and low power mode off.
- Compute checksums matched across engines and every launch reached completion.
- Bars show medians, thick lines show the middle 50% of samples, and whiskers
  show the observed minimum and maximum. They are not confidence intervals.
