This is a live document covering the high level status of the various parts of One. We don't cover all areas, just high level stable, and all developing or unstable sub-areas.

Broadly: web is stable, and native is stable in Metro mode.

### Native <Status is="stable" />

Native supports two bundlers. [Rolldown](https://rolldown.rs) is the default native bundler for development and production builds. [Metro mode](/docs/metro-mode) remains available for dependencies that need it: a Metro-built app is in every way a normal Metro-built app, including building to production and deploying to app stores.

- Local development <Status is="alpha" /> (rolldown dev() with HMR via React Refresh)
- Production builds <Status is="alpha" /> (rolldown build() with treeshaking)
- Assets <Status is="developing" />
- Symbolicator <Status is="early" />
