---
title: Utility Functions
---

Small helpers exported directly by `one`. Each has its own page:

- [redirect](/docs/helpers-redirect) - navigate on the client, return a redirect response on the server
- [getURL](/docs/helpers-getURL) - the current app URL on client or server
- [isResponse](/docs/helpers-isResponse) - check for a Response-like value
- [href](/docs/helpers-href) - build typed route strings
- [setServerData / getServerData](/docs/helpers-serverData) - pass data from the server to the client
- [setResponseHeaders](/docs/helpers-setResponseHeaders) - set headers during server rendering
- [watchFile](/docs/helpers-watchFile) - register loader file dependencies for hot reload
