Developing an app with One is as simple as `one dev`.

It takes the following arguments (see the [CLI reference](/docs/cli) for every command):

```bash
--clean           # boolean, will clear all caches before running
--host            # string, set the hostname to bind to
--port            # string, set the port to bind to
--mode            # "development" or "production": serve the production bundle from the dev server
--debug-bundle    # string, write the bundle to a temp file and serve it from there for debugging
--debug           # string, pass debug args to Vite
--extra-config    # string, path to an extra Vite config file to merge on top of the project config
```

You can also set the port with the `ONE_PORT` or `ONE_FORCE_PORT` environment variables. See [Environment Variables](/docs/environment#server) for details.

The One development server serves both web and native apps on the same port at the same time, and should hot reload both at once. When you see the `Server running on` message with a host and port, that is the same for both native and web.

## Native Development

The `one dev` command only starts the development server — it does not build or run the native iOS/Android shell. One ships native code inside the `one` package, so native development uses your own app build rather than Expo Go:

1. Run `one prebuild` to generate the native Xcode/Android project
2. Run `one run:ios` or `one run:android` to build and launch the app

See the [Build or Run the Native iOS App](/docs/guides-ios-native) guide for detailed instructions.

## Metro Mode

By default, One bundles native apps with Rolldown. If a dependency requires Metro, use [Metro mode](/docs/metro-mode).
