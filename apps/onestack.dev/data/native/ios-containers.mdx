title: iOS Containers
description: Layout and grouping views under One.iOS
---

Layout and grouping views under `One.iOS`. `HStack`, `VStack`, `Form`, and
`Host` also take environment values: `colorScheme`, `dynamicTypeSize`,
`locale`, `tint`, and `isEnabled`.

| Component | Key props |
|-----------|-----------|
| `HStack`, `VStack` | `spacing`, `alignment` |
| `ZStack` | `alignment` |
| `Form` | `sizing` (`fill` or `content`) |
| `Section` | `title`, `footer` |
| `Glass` | `material`, `glassEffect`, `interactive`, `shape`, `cornerRadius`, `tint` |
| `LabeledContent` | `label`, `value`, `systemImage` |
| `List` | `listStyle` |
| `ScrollView` | `axes` (`vertical`, `horizontal`, `both`), `showsIndicators` |
| `LazyVStack`, `LazyHStack` | `alignment`, `spacing` |
| `ControlGroup` | `label`, `systemImage`, `controlGroupStyle` |
| `DisclosureGroup` | `label`, `isExpanded`, `onIsExpandedChange` |
| `Divider` | view props only |
| `Link` | `destination`, `label` |
| `Group` | view props only |
| `Overlay`, `Overlay.Content` | `alignment` |
| `SwipeActions`, `SwipeActions.Actions` | `edge` (`leading` or `trailing`), `allowsFullSwipe` |
| `Pager`, `Page` | `selection`, `onSelectionChange`; pages carry `id` |
| `Spacer` | `minLength` |
| `Slot` | `height`, `width` |
| `Host` | `axis`, `spacing`, `alignment`; carries a React Native subtree into a SwiftUI container |
