`One.UI.Portal` renders its children inside a `One.UI.PortalHost` somewhere
else in the app. The children stay in their place in the React tree.

- Context, state, and event handlers keep working across the move.
- No provider is required.
- Hosted children lay out against the host, not the source.
- It replaces `react-native-teleport`.

## Usage

Mount a host where the content should appear, then name it from a portal.
The host draws portals above its own children.

```tsx
import { One } from 'one'
import { StyleSheet, View } from 'react-native'

export function Screen() {
  return (
    <View style={{ flex: 1 }}>
      <MessageList />
      <One.UI.PortalHost name="overlay" style={StyleSheet.absoluteFill} />
    </View>
  )
}

function MessageRow({ menuOpen }: { menuOpen: boolean }) {
  return (
    <View style={{ overflow: 'hidden' }}>
      <RowContent />
      {menuOpen && (
        <One.UI.Portal hostName="overlay" name="menu">
          <RowMenu />
        </One.UI.Portal>
      )}
    </View>
  )
}
```

The menu escapes the row's clip because it renders in the host, yet it still
reads the row's context and state.

## Behavior

- A host never takes touches itself, so a full-screen host blocks nothing
  under it. Only its portals and children receive touches.
- Portals appear in mount order above the host's own children.
- Unnamed portals coexist. Removing a replacement reveals the portal it replaced.
- Hosted children lay out against the host's size, including percentages and
  absolute right and bottom offsets. Resizing the host lays them out again.
- If the named host has not mounted yet, the portal renders in place and moves
  when the host mounts.
- Removing a host returns its portals to their source.
- Changing `hostName` moves the same children, with their state, to the new host.

| | iOS | Android | Web |
| --- | --- | --- | --- |
| Host | Fabric view | Native view group | Stable DOM container |
| Layout | Host size measured natively, no JS round trip | Same | CSS |

## Migrating from react-native-teleport

Replace imports from `react-native-teleport` with `One.UI.Portal` and
`One.UI.PortalHost`, remove `PortalProvider`, and mount any root overlay host
yourself. `@tamagui/native/setup-teleport` keeps its import path and binds
Tamagui portals to these components.
