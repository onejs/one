---
title: Image
description: Shared images through the native image loader
---

`One.UI.Image` displays local and remote images through Nitro Image on iOS and Android.
Use a URL string, a `{ uri }` source, or a bundled React Native image resource.
On web it renders the platform image with the same props.

| Prop | Type |
|------|------|
| `source` | `string` URL, `{ uri: string }`, or a bundled image resource number (required) |
| `resizeMode` | `'cover'`, `'contain'`, `'center'`, or `'stretch'` |
| `recyclingKey` | `string` that scopes view recycling |
| `onLoad` | `({ nativeEvent: { source: { uri, width, height } } }) => void` |
| `onError` | `({ nativeEvent: { error } }) => void` |

All other React Native image props pass through except `resizeMode`, which
is limited to the four values above. `recyclingKey` keeps recycled views
from flashing old content in lists. `onLoadStart` and `onLoadEnd` fire around
every source change, and the view stays empty until the current source loads.

```tsx
import { One } from 'one'

<One.UI.Image source={{ uri: photoUrl }} resizeMode="cover" style={{ width: 240, height: 160 }} />
```

The loader (`react-native-nitro-image` and `react-native-nitro-web-image`)
ships with `one`, so remote images need no extra install.
