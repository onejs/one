`One.iOS` modal presentations and menus are presented by the system: `Sheet`,
`FullScreenCover`, `Popover`, `Alert`, `ConfirmationDialog`, and `QuickLook`
from SwiftUI, and `Menu` and `ContextMenu` built from UIKit menu elements.
Every presentation is controlled, with `isPresented`, an
`onIsPresentedChange` callback, and a `revision` for resets from the outside.

Reach for a sheet for Peek-style detail over content, a full screen cover for
an immersive task with its own close control, a popover for an anchored panel,
an alert or confirmation dialog for a short choice, and a menu for a list of
actions on a trigger. Every view here throws on web and Android.

## Usage

```tsx
import { useState } from 'react'
import { Text } from 'react-native'
import { One } from 'one'

function TripDetails() {
  return <Text>Departs Oct 14, 9:30 AM.</Text>
}

export function TripScreen() {
  const [open, setOpen] = useState(false)

  return (
    <>
      <One.iOS.Button label="Details" onPress={() => setOpen(true)} />
      <One.iOS.Sheet
        isPresented={open}
        onIsPresentedChange={setOpen}
        presentationDetents={['medium', 'large']}
        presentationDragIndicator="visible"
      >
        <TripDetails />
      </One.iOS.Sheet>
    </>
  )
}
```

`onIsPresentedChange(false)` asks React to close the presentation, after a
swipe down or a tap outside. Accept it by setting the state, or decline it by
leaving `isPresented` true. To change the presentation from outside, set the
new value and increase `revision` in the same render.

## How it works

Presentations keep their flag in a native model with an event count and a
revision, like any controlled value. A native open or close request bumps the
count and reports the proposal; JavaScript calls the change handler and
acknowledges the event. The presentation moves only when the prop updates, so
leaving `isPresented` true declines a swipe-to-dismiss.

Sheets and covers host React Native children in a native content view; the
sheet chrome itself, detents, drag indicator, background, and sizing, is
SwiftUI's. `onDismiss` forwards SwiftUI's dismissal. Menus take a different
shape: an
array of item data rendered as `UIMenu` and `UIAction` elements, with taps,
toggle flips, and picker choices reported by item id.

## Sheet

`Sheet` presents its children in a sheet.

```tsx

import { One } from 'one'

      <One.iOS.Sheet
        isPresented={open}
        onIsPresentedChange={setOpen}

        presentationDragIndicator="visible"

        <Text>Departs Oct 14, 9:30 AM.</Text>
```

A `PresentationDetent` is `'medium'`, `'large'`, `{ fraction }` from 0 to 1,
or `{ height }` in points. At least one detent is required and each must be
unique, and a selected detent must be one of `presentationDetents`.
`presentationBackgroundInteraction` is `'automatic'`, `'enabled'`,
`'disabled'`, or `{ enabledUpThrough: detent }`, which lets the screen behind
take touches until the sheet grows past that detent; the detent must be one of
`presentationDetents`.

## FullScreenCover

`FullScreenCover` covers the screen. It has no detents and no swipe to
dismiss, so the content needs its own close control.

```tsx
import { useState } from 'react'
import { Button, View } from 'react-native'
import { One } from 'one'

function PlayerCover() {
  const [open, setOpen] = useState(false)

  return (
    <>
      <One.iOS.Button label="Play" onPress={() => setOpen(true)} />
      <One.iOS.FullScreenCover isPresented={open} onIsPresentedChange={setOpen}>
        <View style={{ flex: 1 }}>
          <Button title="Close" onPress={() => setOpen(false)} />
        </View>
      </One.iOS.FullScreenCover>
    </>
  )
}
```

## Popover

## Alert

`Alert` shows a system alert with one button per action.

```tsx
import { useState } from 'react'
import { One } from 'one'

function DeleteTrip({ deleteTrip }: { deleteTrip: () => void }) {
  const [confirming, setConfirming] = useState(false)

  return (
    <>
      <One.iOS.Button label="Delete" onPress={() => setConfirming(true)} />
      <One.iOS.Alert
        isPresented={confirming}
        onIsPresentedChange={setConfirming}
        title="Delete trip?"
        message="This removes it from every device."
        actions={[
          { id: 'cancel', label: 'Cancel', role: 'cancel' },
          { id: 'delete', label: 'Delete', role: 'destructive' },
        ]}
        onAction={(id) => {
          if (id === 'delete') deleteTrip()
        }}
      />
    </>
  )
}
```

A `DialogAction` is `{ id, label, role }`, where `role` is a `ButtonRole`:
`'destructive'`, `'cancel'`, `'confirm'`, or `'close'`. Actions need string
ids and labels with unique ids.

## ConfirmationDialog

`ConfirmationDialog` shows an action sheet. It takes every `Alert` prop plus
`titleVisibility`.

```tsx

import { One } from 'one'

function TripOptions({ remove }: { remove: () => void }) {
  const [open, setOpen] = useState(false)

  return (
    <>
      <One.iOS.Button label="Options" onPress={() => setOpen(true)} />
      <One.iOS.ConfirmationDialog
        isPresented={open}
        onIsPresentedChange={setOpen}
        title="Trip options"
        actions={[
          { id: 'remove', label: 'Remove', role: 'destructive' },
          { id: 'cancel', label: 'Cancel', role: 'cancel' },
        ]}
        onAction={(id) => {
          if (id === 'remove') remove()
```

## QuickLook

`QuickLook` previews a document while `isPresented` is true. The URL must be a
non-empty `file`, `http`, or `https` URL, or the view throws.

```tsx
function Itinerary({ url }: { url: string }) {
```

## Menu

`Menu` renders its children as the trigger and opens a menu on tap. With
`primaryAction`, a tap runs the action and the menu opens on long press
instead. Items with toggles require `onValueChange`; items with pickers
require `onPickerChange`.

```tsx
import { One } from 'one'

function TripMenu({ act }: { act: (id: string) => void }) {
  return (
    <One.iOS.Menu
      accessibilityLabel="Options"
      items={[
        { type: 'action', id: 'share', title: 'Share', systemImage: 'square.and.arrow.up' },
        { type: 'divider', id: 'sep' },
        { type: 'action', id: 'delete', title: 'Delete', role: 'destructive' },
      ]}
      onAction={act}
    >
      <One.iOS.Image systemName="ellipsis.circle" />
    </One.iOS.Menu>
  )
}
```

### Menu items

Each item has a `type`, and every id must be unique and nonempty. A `picker`
shows its options as a submenu with a checkmark on the selected one;
`selection` names one of its children's ids, and `onPickerChange` reports the
new one. A `toggle` carries one boolean per source in `values`: it shows on
when every source is true, mixed when some are, and off when none are, and a
tap flips every source, reporting each index through `onValueChange`.

## ContextMenu

`ContextMenu` takes the same props as `Menu`, without `primaryAction`, and
opens on long press. Its `accessibilityLabel` is optional and the trigger
keeps its own touches.

```tsx
import { Text } from 'react-native'
import { One } from 'one'

function TripRow({ act }: { act: (id: string) => void }) {
  return (
    <One.iOS.ContextMenu
      items={[
        { type: 'action', id: 'share', title: 'Share' },
        { type: 'action', id: 'delete', title: 'Delete', role: 'destructive' },
      ]}
      onAction={act}
    >
      <Text>Lisbon, Oct 14</Text>
    </One.iOS.ContextMenu>
  )
}
```

## Platform differences

| | iOS | Android | Web |
| --- | --- | --- | --- |
| Renders | System sheets | Throws | Throws |
| Detents | Native stops | None | None |
| Menus | UIKit menus | None | None |

## Limits and gotchas

- **Declining a close leaves the flag true.** A swipe-to-dismiss only proposes;
  the presentation stays until `isPresented` goes false.
- **Sheet detents are strict.** At least one is required, each must be unique,
  and the selected and interaction detents must be members of
  `presentationDetents`.
- **Menus need their callbacks.** Items with toggles throw without
  `onValueChange`; items with pickers throw without `onPickerChange`.
