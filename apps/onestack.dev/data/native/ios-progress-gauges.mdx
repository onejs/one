`One.iOS` progress and measurement views are SwiftUI's own: `ProgressView`
shows a determinate bar or an indeterminate spinner, and `Gauge` shows a value
in a range with optional labels. Both take plain numbers, validated at render:
out-of-range values throw.

Reach for `ProgressView` for work with a known or unknown total, and `Gauge`
for a measurement against fixed bounds such as speed. Both throw on web and
Android.

## Usage

```tsx
import { One } from 'one'

function Download({ downloaded, size }: { downloaded: number; size: number }) {
  return (
    <>
      <One.iOS.ProgressView label="Download" value={downloaded} total={size} />
      <One.iOS.ProgressView label="Loading" />
    </>
  )
}
```

A set `value` draws a determinate bar; an unset one draws a spinner.

Both also accept `accessibilityLabel`, `accessibilityHint`,
`accessibilityValue`, `testID`, `style`, `onLayout`, and `swiftStyle`.

## How it works

Progress and gauge state is plain props, not controlled values: there is no
native editing, so no revision or change callback. The wrappers validate the
numbers before they reach native, then the SwiftUI view draws them.
`progressViewStyle` and `gaugeStyle` are SwiftUI modifiers set through
`swiftStyle`, and their names are checked against the device's iOS version.

## ProgressView

`ProgressView` shows determinate progress when `value` is set and a spinner
when it is not. `value` must be finite and lie between 0 and `total`, and
`total` must be finite and above zero, or the view throws.

```tsx
import { One } from 'one'

function Sync({ done, total }: { done: number; total: number }) {
  return (
    <One.iOS.ProgressView
      label="Sync"
      value={done}
      total={total}
      swiftStyle={{ progressViewStyle: 'linear' }}
    />
  )
}
```

## Gauge

`Gauge` shows `value` between `minimumValue` and `maximumValue`. Every number
must be finite, the minimum must be below the maximum, and the value must lie
within the range, or the gauge throws.

```tsx
import { One } from 'one'

function Speed({ speed }: { speed: number }) {
  return (
    <One.iOS.Gauge
      label="Speed"
      value={speed}
      maximumValue={120}
      currentValueLabel={`${speed}`}
      swiftStyle={{ gaugeStyle: 'accessoryCircular' }}
    />
  )
}
```

## Platform differences

| | iOS | Android | Web |
| --- | --- | --- | --- |
| Renders | SwiftUI views | Throws | Throws |
| Styles | Native styles | None | None |

## Limits and gotchas

- **Ranges are checked at render.** A value outside its bounds, a total at or
  below zero, or an inverted gauge range throws.
- **Progress is one way.** These views take numbers and report nothing back;
  there is no change callback or revision.
