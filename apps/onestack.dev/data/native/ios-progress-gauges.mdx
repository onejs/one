Progress and measurement views under `One.iOS`, drawn by SwiftUI.

- `ProgressView` shows a determinate bar or an indeterminate spinner.
- `Gauge` shows a value in a range, with optional labels.
- Out-of-range values throw during render.
- Both throw on web and Android. Keep them in an iOS branch or an `.ios.tsx`
  file.

## Usage

```tsx
import { One } from 'one'

<One.iOS.ProgressView label="Download" value={downloaded} total={size} />
<One.iOS.ProgressView label="Loading" />
<One.iOS.Gauge
  label="Speed"
  value={speed}
  maximumValue={120}
  currentValueLabel={`${speed}`}
  gaugeStyle="accessoryCircular"
/>
```

Both also accept `accessibilityLabel`, `accessibilityHint`,
`accessibilityValue`, `testID`, `style`, `onLayout`, and `swiftStyle`.
