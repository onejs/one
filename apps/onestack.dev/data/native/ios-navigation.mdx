Navigation chrome under `One.iOS`. This is the SwiftUI toolbar that fills
the navigation bar, distinct from the UIKit navigation toolbar
(`One.iOS.ToolbarHost` and `One.iOS.BarButtonItem`) covered in
[Toolbar and Menus](/native/toolbar).

## NavigationStack

`One.iOS.NavigationStack` is a SwiftUI navigation stack whose root is the
React Native content beside it. Children are `Toolbar` elements (which fill
the navigation bar) or React Native content; `ToolbarItem`,
`ToolbarItemGroup`, and `ToolbarSpacer` belong inside a `Toolbar`, never
directly in the stack. Navigation title, title display mode, and every
other scalar navigation or toolbar modifier reach the stack through
`swiftStyle`, so the bar has no bespoke props.

```tsx
import { One } from 'one'

<One.iOS.NavigationStack>
  <One.iOS.Toolbar>
    <One.iOS.ToolbarItem placement="primaryAction">
      <One.iOS.Button label="Save" onPress={save} />
    </One.iOS.ToolbarItem>
  </One.iOS.Toolbar>
  <Content />
</One.iOS.NavigationStack>
```

## NavigationSplitView

`One.iOS.NavigationSplitView` uses SwiftUI's two or three column split view.
Its direct children are one `Sidebar`, an optional `Content`, and one
`Detail`. Each column accepts React Native content and a column `swiftStyle`.
Column styles can set their own navigation title and other SwiftUI modifiers.

```tsx
import { One } from 'one'

<One.iOS.NavigationSplitView
  columnVisibility={columnVisibility}
  onColumnVisibilityChange={setColumnVisibility}
  preferredCompactColumn={compactColumn}
  onPreferredCompactColumnChange={setCompactColumn}
>
  <One.iOS.NavigationSplitView.Sidebar
    swiftStyle={{ navigationTitleWithText: 'Mailboxes' }}
  >
    <One.iOS.Toolbar>
      <One.iOS.List selection={selection} onSelectionChange={setSelection}>
        {mailboxes.map((mailbox) => (
          <One.iOS.Label
            key={mailbox.id}
            label={mailbox.name}
            systemImage="tray"
            swiftStyle={{ tag: mailbox.id }}
          />
        ))}
      </One.iOS.List>
      <One.iOS.Toolbar.Content>
        <One.iOS.ToolbarItem placement="topBarTrailing">
          <One.iOS.Button label="Add" onPress={addMailbox} />
        </One.iOS.ToolbarItem>
      </One.iOS.Toolbar.Content>
    </One.iOS.Toolbar>
  </One.iOS.NavigationSplitView.Sidebar>
  <One.iOS.NavigationSplitView.Detail>
    <MessageDetail />
  </One.iOS.NavigationSplitView.Detail>
</One.iOS.NavigationSplitView>
```

Omit `columnVisibility` and `preferredCompactColumn` to let SwiftUI manage
them. Supplying either prop makes it controlled: its callback reports the
native proposal, and the prop remains authoritative until React updates it.
`columnVisibility` is `automatic`, `all`, `doubleColumn`, or `detailOnly`;
`preferredCompactColumn` is `sidebar`, `content`, or `detail` and applies on
iOS 17 or later.

Each column marker is a direct child of `NavigationSplitView`. `Toolbar` wraps
that column's content; its `Toolbar.Content` child holds the toolbar items.
Use `swiftStyle` on a column marker for its navigation title and other
column-level modifiers.

## Toolbar

`One.iOS.Toolbar` becomes one native toolbar. In a `NavigationStack` or
`Tabs`, its children are `ToolbarItem`, `ToolbarItemGroup`, or
`ToolbarSpacer` elements in order. A split view column uses `Toolbar` as a
content wrapper and puts those toolbar entries inside `Toolbar.Content`.
`NavigationStack` merges every toolbar it is given. `One.iOS.Tabs` also takes
a `Toolbar` child.

## Toolbar.Content

`One.iOS.Toolbar.Content` marks the toolbar entries inside a split view
column's content wrapper. Its children follow the same order and types as a
regular toolbar.

## ToolbarItem

`One.iOS.ToolbarItem` places one item in the bar.

<PropsTable
  title="Props"
  source="generated/containerTypes.ts#ToolbarItemProps"
  data={[
    { name: 'placement', type: 'ToolbarItemPlacement', default: '"automatic"', description: 'Where the item goes. See below.' },
    { name: 'children', required: true, type: 'ReactNode', description: 'The item, such as a One.iOS.Button.' },
  ]}
/>

`ToolbarItemPlacement` is every SwiftUI placement: `automatic`, `principal`,
`navigation`, `primaryAction`, `secondaryAction`, `status`,
`confirmationAction`, `cancellationAction`, `destructiveAction`, `keyboard`,
`topBarLeading`, `topBarTrailing`, `topBarPinnedTrailing`,
`navigationBarLeading`, `navigationBarTrailing`, `title`, `largeTitle`,
`bottomBar`, `subtitle`, and `largeSubtitle`. A placement newer than the
running iOS throws.
