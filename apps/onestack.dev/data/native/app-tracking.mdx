title: App Tracking
description: Request and inspect iOS App Tracking Transparency permission
---

`One.AppTracking` exposes the App Tracking Transparency status and the
one-time permission request. Use it when your app needs permission for
tracking across other companies' apps or websites.

On iOS it reads `ATTrackingManager` and requests authorization on the
main thread. On Android and web both methods return denied.

## Usage

```tsx
import { One } from 'one'

const before = One.AppTracking.getPermissionStatus()
if (before === 'notDetermined') {
  const after = await One.AppTracking.requestPermission()
  if (after === 'authorized') {
    // start the tracking-dependent feature
  }
}
```

The status is not determined, restricted, denied, or authorized.
Requesting after the system has decided returns the current status
without prompting again.

## How it works

Add a non-empty `NSUserTrackingUsageDescription` to the iOS Info.plist
before building via `native.app.ios.infoPlist`; without it the request
rejects as a manifest error. Concurrent calls share the same request.
The system prompts only while the app is active with no other
permission prompt pending. An inactive app rejects the request; if iOS
dismisses the prompt without a choice, the request returns not
determined, so ask again once the app is active and other prompts have
closed.

## Platform differences

| | iOS | Android | Web |
| --- | --- | --- | --- |
| Engine | Tracking hub | None | None |
| Status | Four states | Denied | Denied |
| Prompt | Once | Never | Never |

## Limits and gotchas

- **The prompt shows once.** After a decision the request returns the
  status silently. Send undecided users to Settings instead of
  re-requesting in a loop.
- **Ask while active and alone.** Background requests reject, and a
  pending prompt from another API suppresses this one. Sequence
  permission prompts deliberately.
- **Not determined can repeat.** A dismissed-without-choice prompt
  returns not determined. Retry after activation, not immediately.
- **The usage string is mandatory.** An empty or missing description
  rejects every request before anything prompts.

## Examples

### Gate an analytics SDK

```tsx
import { One } from 'one'

async function enableTracking(start: () => void) {
  if (One.AppTracking.getPermissionStatus() !== 'notDetermined') return
  const status = await One.AppTracking.requestPermission()
  if (status === 'authorized') start()
}
```

The pre-check skips decided users without a wasted request. Only an
explicit grant starts the tracking-dependent SDK.

### Explain before asking

```tsx
import { useState } from 'react'
import { Button, Text } from 'react-native'
import { One } from 'one'

function TrackingPrimer({ onDone }: { onDone: () => void }) {
  const [asked, setAsked] = useState(false)

  async function ask() {
    setAsked(true)
    await One.AppTracking.requestPermission()
    onDone()
  }

  if (asked) return null
  return (
    <>
      <Text>Personalized ads support free features. You can change this in Settings.</Text>
      <Button title="Continue" onPress={ask} />
    </>
  )
}
```

A primer screen states the value before the system prompt appears,
which is the only moment your own words can precede Apple's. The
component unmounts itself once the request settles.
