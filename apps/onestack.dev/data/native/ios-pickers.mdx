Value pickers and system choosers under `One.iOS`, drawn by SwiftUI.

- `Picker`, `DatePicker`, and `ColorPicker` are controlled: a `selection`, an
  `onSelectionChange` callback, and a `revision` for external resets.
- `PhotosPicker` and `FileImporter` open the system photo library and file
  browser.
- Invalid values throw during render.
- Every picker throws on web and Android. Keep them in an iOS branch or an
  `.ios.tsx` file.

## Usage

```tsx
import { useState } from 'react'
import { One } from 'one'

export function TripForm() {
  const [seat, setSeat] = useState('window')
  const [date, setDate] = useState(() => new Date())

  return (
    <One.iOS.Form style={{ flex: 1 }}>
      <One.iOS.Section>
        <One.iOS.Picker
          label="Seat"
          selection={seat}
          onSelectionChange={setSeat}
          pickerStyle="segmented"
          options={[
            { value: 'window', label: 'Window' },
            { value: 'aisle', label: 'Aisle' },
          ]}
        />
        <One.iOS.DatePicker
          label="Departure"
          selection={date}
          onSelectionChange={setDate}
          minimumDate={new Date()}
        />
      </One.iOS.Section>
    </One.iOS.Form>
  )
}
```

## Shared props

Every picker also accepts `accessibilityLabel`, `accessibilityHint`,
`accessibilityValue`, `testID`, `style`, `onLayout`, and `swiftStyle`.

## PhotosPicker

`One.iOS.PhotosPicker` is a button that opens the system photo library.

```tsx
<One.iOS.PhotosPicker
  label="Add photos"
  onPick={(url) => addPhoto(url)}
  onPickError={(message) => setError(message)}
  maxSelectionCount={5}
  filter="images"
/>
```

## FileImporter

`One.iOS.FileImporter` presents the system file browser while `isPresented`
is true.

`{ type: 'failed', message }`, or `{ type: 'cancelled' }`.
