---
title: Pager
description: Swipe between React Native pages on iOS, Android, and web
---

`One.UI.Pager` fills its viewport with one direct child view per page.
iOS uses a paging `UIScrollView`, Android uses `ViewPager2`, and web uses
CSS scroll snap. Give the pager a size, and keep a stable key on each page.

```tsx
import { useRef, useState } from 'react'
import { One, type PagerRef } from 'one'
import { View, Text } from 'react-native'

export function ProjectPages() {
  const pager = useRef<PagerRef>(null)
  const [page, setPage] = useState(0)

  return (
    <One.UI.Pager
      ref={pager}
      style={{ flex: 1 }}
      initialPage={0}
      onPageSelected={({ nativeEvent }) => setPage(nativeEvent.position)}
    >
      <View key="projects">
        <Text>Projects, page {page + 1}</Text>
        <Text onPress={() => pager.current?.setPage(1)}>Open chat</Text>
      </View>
      <View key="chat">
        <Text>Chat, page {page + 1}</Text>
        <Text onPress={() => pager.current?.setPageWithoutAnimation(0)}>
          Back to projects
        </Text>
      </View>
    </One.UI.Pager>
  )
}
```

`onPageScroll` delivers `{ position, offset }` throughout a drag or animated
settle. A completed settle delivers the landing page with `offset: 0`.
Use this event as the single writer of continuous progress;
`onPageSelected` reports the selected page, and
`onPageScrollStateChanged` reports `{ pageScrollState }`, one of `idle`,
`dragging`, and `settling`.

| Prop | Default | Behavior |
| --- | --- | --- |
| `initialPage` | `0` | Starting index, read on mount |
| `scrollEnabled` | `true` | Enables user swipes; commands still work |
| `orientation` | `horizontal` | `horizontal` or `vertical` |
| `layoutDirection` | `ltr` | `ltr` or `rtl`; indices retain child order |
| `pageMargin` | `0` | Space between pages in points |
| `keyboardDismissMode` | `none` | `none` or `on-drag` |
| `overdrag` | `false` | Enables bouncing at the ends on iOS |
| `offscreenPageLimit` | `-1` | Android cache limit; `-1` or a positive integer |
| `overScrollMode` | `auto` | Android edge effect: `auto`, `always`, or `never` |

`setPage(index)` animates to a page; `setPageWithoutAnimation(index)` moves
immediately. `setScrollEnabled(enabled)` changes whether user swipes are enabled.
The page commands take a nonnegative integer index. An index beyond the mounted
pages does nothing. Removing the selected last page selects the last remaining
page. A resize preserves the selected page. Invalid prop values and invalid
index types throw synchronously on all platforms.

The pager has no automatic safe-area or keyboard inset adjustment. Its children
own those insets. Children stay in the React tree and inherit appearance changes.
For SwiftUI pages with string selection and `One.iOS.Page` children, use
`One.iOS.Pager`.

To migrate from `react-native-pager-view`, replace its default import and JSX
with `One.UI.Pager`, and type the ref as `PagerRef` from `one`.
