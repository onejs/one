Jetpack Compose views under `One.Android`, drawn by Material 3.

- Layout nodes such as `Column`, `Row`, `Box`, cards, chips, and icon buttons
  take Compose children.
- Leaves such as `Text`, `Icon`, `Button`, `Switch`, `TextField`, and `Slider`
  take none.
- Controls are controlled: a value, a change callback, and a `revision` for
  external resets.
- Every view throws outside an Android build, including on web. Keep them in
  an Android branch or an `.android.tsx` file.

## Usage

```tsx
import { useState } from 'react'
import { One } from 'one'

export function Settings() {
  const [on, setOn] = useState(true)

  return (
    <One.Android.Card composeStyle={{ padding: 16 }}>
      <One.Android.Switch label="Airplane mode" isOn={on} onIsOnChange={setOn} />
    </One.Android.Card>
  )
}
```

## DatePicker, TimePicker

`One.Android.DatePicker` is the Material 3 calendar and `One.Android.TimePicker`
is the clock dial. Both are controlled by a `Date`. DatePicker changes the
calendar day in the device time zone and keeps the time of day. TimePicker
changes the hour and minute, keeps the day, and sets seconds to zero.

```tsx
const [when, setWhen] = useState(() => new Date())

<One.Android.DatePicker
  selection={when}
  onSelectionChange={setWhen}
  minimumDate={new Date(2026, 0, 1)}
/>
<One.Android.TimePicker selection={when} onSelectionChange={setWhen} is24Hour />
```
