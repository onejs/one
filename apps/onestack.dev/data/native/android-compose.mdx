---
title: Android Compose
description: Jetpack Compose views under One.Android
---

Jetpack Compose views under `One.Android`. Layout nodes (`Column`, `Row`, `FlowRow`,
`Box`, `BadgedBox`, `Badge`, `ListItem`, `Card`, `ElevatedCard`, `OutlinedCard`, `AssistChip`, `FilterChip`,
`InputChip`, `SuggestionChip`, `IconButton`, `FilledIconButton`, `FilledTonalIconButton`,
`OutlinedIconButton`) take children;
`Text`, `Icon`,
`Button`, `Switch`, `Checkbox`, `RadioButton`, `HorizontalDivider`,
`VerticalDivider`, `TextField`,
`Slider`, `AlertDialog`, and `ProgressIndicator` are leaves. `Dialog`
takes children and shows them in a dialog window. Every node takes the
shared props (`accessibilityLabel`, `accessibilityState`,
`accessibilityValue`, `accessibilityRole`, `testID`, `style`) plus
`composeStyle`: background and foreground colors, padding, width, height,
`fillMaxWidth`, `fillMaxHeight`, `cornerRadius`, `opacity`, border color
and width. A node nested in a Compose tree styles through `composeStyle`;
`style` applies only at the root of the tree.

## Column, Row, Box

`One.Android.Column` stacks children vertically with
`horizontalAlignment` (`'start'`, `'centerHorizontally'`, `'end'`) and
`verticalArrangement` (`'top'`, `'center'`, `'bottom'`, `'spaceBetween'`,
`'spaceAround'`, `'spaceEvenly'`). `One.Android.Row` is the horizontal
mirror with `verticalAlignment` (`'top'`, `'centerVertically'`,
`'bottom'`) and `horizontalArrangement` (same six values). Both take
`spacing` in dp. `One.Android.Box` layers children with
`contentAlignment` (`'topStart'`, `'topCenter'`, `'topEnd'`,
`'centerStart'`, `'center'`, `'centerEnd'`, `'bottomStart'`,
`'bottomCenter'`, `'bottomEnd'`, `'top'`, `'bottom'`, `'start'`, `'end'`).
`One.Android.FlowRow` wraps children across rows. Its horizontal and vertical
arrangements accept the same distribution names as `Row` and `Column`, or
`{ spacedBy: number }` for spacing in dp on that axis.

```tsx
import { One } from 'one'

<One.Android.Column spacing={12}>
  <One.Android.Text text="Airplane mode" />
  <One.Android.Switch isOn={on} onIsOnChange={setOn} />
</One.Android.Column>
```

## Text

`One.Android.Text` renders `text` with `fontSize` in sp, `fontWeight`
(`'thin'` through `'black'`), `textAlign` (`'unspecified'`, `'left'`,
`'right'`, `'center'`, `'justify'`, `'start'`, `'end'`), and `maxLines`.

## Icon

`One.Android.Icon` renders a Material icon by `name` with `size` in dp
(default 24) and `filled` for the filled variant. For a cross-platform icon
that also renders on iOS and web, use [One.UI.Icon](/native/icons) with
per-platform elements instead.

## Button

`One.Android.Button` shows `label` with an optional `icon` (and
`iconFilled`). `variant` is `'filled'`, `'tonal'`, `'elevated'`,
`'outlined'`, or `'text'`; `tone`
is `'default'` or `'danger'`; `disabled` disables it; `onPress` handles
taps.

`One.Android.IconButton`, `FilledIconButton`, `FilledTonalIconButton`, and
`OutlinedIconButton` wrap an `Icon` child. Each accepts `enabled`, `onClick`,
and `colors` with `containerColor`, `contentColor`, `disabledContainerColor`,
and `disabledContentColor`. Omitted colors use the current Material theme.

`One.Android.FloatingActionButton`, `SmallFloatingActionButton`,
`LargeFloatingActionButton`, and `ExtendedFloatingActionButton` render the
Material 3 floating button sizes. Put an `Icon` in their `.Icon` slot and, for
the extended variant, `Text` in `.Text`. `containerColor` overrides the theme,
`onClick` handles taps, and `expanded` controls the extended label.

## Switch

`One.Android.Switch` is the Compose toggle: `isOn` with `onIsOnChange`
(required), an optional `label`, `disabled`, and `revision` for external
resets.

## Checkbox

`One.Android.Checkbox` uses a controlled `value` and optional
`onCheckedChange`. With no callback it is read only. `disabled` prevents
interaction, and `revision` applies an external reset. `colors` accepts
`checkedColor`, `disabledCheckedColor`, `uncheckedColor`,
`disabledUncheckedColor`, and `checkmarkColor`; omitted colors use the
current Material theme.

## RadioButton

`One.Android.RadioButton` takes a controlled `selected` value and optional
`onClick`. Without a callback it is read only. `disabled` prevents clicks.
The `colors` prop accepts `selectedColor`, `unselectedColor`,
`disabledSelectedColor`, and `disabledUnselectedColor`; omitted colors use
the current Material theme.

## Cards

`One.Android.Card`, `ElevatedCard`, and `OutlinedCard` wrap Compose children
in the corresponding Material 3 surface. Each accepts `colors` with optional
`containerColor` and `contentColor`, plus an optional nonnegative `elevation`
in dp. `Card` and `OutlinedCard` also accept `border` with optional `width`
in dp (default 1) and `color`. An omitted border leaves `Card` unbordered and
uses the Material theme's outline for `OutlinedCard`.

## List items

`One.Android.ListItem` renders a Material 3 row. Put Compose content in its
`.HeadlineContent`, `.OverlineContent`, `.SupportingContent`, `.LeadingContent`,
and `.TrailingContent` slots. The headline is the main line; the other slots
are optional. `colors` accepts `containerColor`, `contentColor`,
`leadingContentColor`, `trailingContentColor`, `supportingContentColor`, and
`overlineContentColor`. `tonalElevation` and `shadowElevation` are nonnegative
dp values; omitted values use the Material defaults.

## Dividers

`One.Android.HorizontalDivider` and `VerticalDivider` draw Material 3 lines
inside a Compose layout. Both accept optional `thickness` in dp and `color`;
omitted values use the current Material theme. Give a vertical divider a height
through its parent layout or `composeStyle`.

## Badges

`One.Android.Badge` renders a Material 3 indicator dot with no children, or a
count pill when given Compose content. `containerColor` and `contentColor`
override the Material defaults. `One.Android.BadgedBox` places a badge at the
top end of its content. Put a `Badge` inside its `BadgedBox.Badge` slot; without
the slot it renders the default indicator dot.

## Chips

`One.Android.AssistChip`, `FilterChip`, `InputChip`, and `SuggestionChip`
use the corresponding Material 3 components. Every chip accepts `enabled`,
`onClick`, optional `colors`, `elevation` in dp, and `border` with optional
`width` in dp and `color`.

Each chip takes Compose children in named slots. All four have `.Label`.
`AssistChip` and `FilterChip` also have `.LeadingIcon` and `.TrailingIcon`;
`InputChip` has `.Avatar` and `.TrailingIcon`; `SuggestionChip` has `.Icon`.

`FilterChip` requires `selected`; `InputChip` accepts optional `selected`.
Clicks report through `onClick`, while the caller supplies the next selected
value. The available color keys match Expo UI's per-variant keys: `AssistChip`
has `containerColor`, `labelColor`, `leadingIconContentColor`, and
`trailingIconContentColor`; `FilterChip` has `containerColor`, `labelColor`, `iconColor`,
`selectedContainerColor`, `selectedLabelColor`, `selectedLeadingIconColor`,
and `selectedTrailingIconColor`; `InputChip` also has `leadingIconColor` and
`trailingIconColor` in place of `iconColor`; `SuggestionChip` has
`containerColor`, `labelColor`, and `iconContentColor`.

## TextField

`One.Android.TextField` edits `text` (a string or a native state handle
from `useNativeState`) and reports `onTextChange` (required).
`revision` resets externally.

| Prop | Type |
|------|------|
| `label`, `placeholder` | `string` |
| `variant` | `'filled'` or `'outlined'` |
| `keyboardType` | `'default'`, `'number'`, `'decimal'`, `'email'`, `'password'`, `'phone'`, `'url'` |
| `secureText` | `boolean` |
| `disabled` | `boolean` |
| `focused`, `focusRevision` | `boolean`, `number` |
| `onFocusChange` | `(focused: boolean) => void` |
| `imeAction` | `'default'`, `'none'`, `'go'`, `'search'`, `'send'`, `'previous'`, `'next'`, `'done'` |
| `onSubmit` | `() => void` |
| `maxLength` | `number` |
| `multiline` | `boolean` |
| `capitalization` | `'none'`, `'characters'`, `'words'`, `'sentences'` |
| `autoCorrect` | `boolean` |
| `textAlign` | text align |

For a cross-platform field that also runs on iOS and web, use
[One.UI.TextInput](/native/text-input) instead.

## Slider

`One.Android.Slider` picks a number with `value` and `onValueChange`
(required), `revision`, `minimumValue`, `maximumValue`, `step`, and
`disabled`.

## AlertDialog, Dialog

`One.Android.AlertDialog` shows a confirmation while `visible` is true.
`title` and `message` are strings; `confirmLabel` (required) and
`dismissLabel` name the buttons; `onConfirm` and `onDismiss` (both
required) handle them. `One.Android.Dialog` shows its children in a dialog
window while `visible` is true and reports dismissal through `onDismiss`.

## ProgressIndicator

`One.Android.ProgressIndicator` shows progress as `'linear'` or
`'circular'` (default circular). Leave `progress` undefined for an
indeterminate indicator.

`One.Android` components throw when rendered outside an Android build, so
keep those branches behind platform checks.
