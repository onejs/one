---
title: iOS Text and Fields
description: Text, Label, TextField, SecureField, and TextEditor under One.iOS
---

Text display and text entry under `One.iOS`. `TextField` and `SecureField`
take a plain string or a `NativeState` handle from
`useNativeState`, so keystrokes stay correct without a React render.
Both follow the controlled pattern with `revision`, focus props
(`focused`, `onFocusChange`, `focusRevision`), and `onSubmit`.

## Text

`One.iOS.Text` renders one string with `text`. It takes no other props
beyond the shared view props.

## Label

`One.iOS.Label` renders a title with an icon: `label` plus `systemImage`,
an SF Symbol name.

```tsx
import { One } from 'one'

<One.iOS.Label label="Favorites" systemImage="star" />
```

## TextField

`One.iOS.TextField` is a single or multi-line field. `prompt` is the
placeholder, `textFieldStyle` selects the SwiftUI text field style, and
`axis` switches between horizontal and multi-line layout.

| Prop | Type |
|------|------|
| `text` | `string` or `NativeState<string>` |
| `onTextChange` | `(value: string) => void` |
| `revision` | `number` |
| `focused`, `focusRevision` | `boolean`, `number` |
| `onFocusChange` | `(focused: boolean) => void` |
| `onSubmit` | `() => void` |
| `prompt` | `string` |
| `textFieldStyle` | SwiftUI text field style |
| `submitLabel` | SwiftUI submit label, or `''` |
| `textInputAutocapitalization` | SwiftUI text input autocapitalization, or `''` |
| `autocorrectionDisabled` | `boolean` |
| `keyboardType` | keyboard type, or `''` |
| `textContentType` | text content type, or `''` |
| `axis` | SwiftUI axis |

```tsx
import { One, useNativeState } from 'one'

function NameField() {
  const name = useNativeState('')

  return (
    <One.iOS.TextField
      label="Name"
      text={name}
      onTextChange={(value) => name.set(value)}
      prompt="Ada Lovelace"
    />
  )
}
```

## SecureField

`One.iOS.SecureField` has the same props as `TextField` and obscures its
input for passwords.

## TextEditor

`One.iOS.TextEditor` is SwiftUI's multi-line editor. Return inserts a newline,
and the editor scrolls its text inside the box React Native gives it, so give
it a height. It takes the controlled `text`, `onTextChange`, `revision`, the
focus props, `textInputAutocapitalization`, `autocorrectionDisabled`,
`keyboardType`, and `textContentType`. SwiftUI's `TextEditor` has no label,
placeholder, style, or submit, so neither does this one; name it with
`accessibilityLabel`.

```tsx
import { useState } from 'react'
import { One } from 'one'

function Notes() {
  const [notes, setNotes] = useState('')

  return (
    <One.iOS.TextEditor
      text={notes}
      onTextChange={setNotes}
      accessibilityLabel="Notes"
      style={{ height: 160 }}
    />
  )
}
```

For a cross-platform field that also runs on Android and web, use
[One.UI.TextInput](/native/text-input) instead. The iOS fields here throw
outside iOS builds.
