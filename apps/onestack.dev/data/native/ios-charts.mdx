title: iOS Charts
description: Swift Charts under One.iOS.Chart
---

`One.iOS.Chart` draws a Swift Charts chart.

- Each data point becomes one mark of the chosen `type`.
- `referenceLines` draw horizontal rule marks at their `y` values.
- Each mark type has its own style object.
- The chart throws on web and Android. Keep it in an iOS branch or an
  `.ios.tsx` file.

A chart fills the box React Native gives it, so give it a height.

```tsx
import { One } from 'one'

<One.iOS.Chart
  type="bar"
  data={[
    { x: 'Mon', y: 3 },
    { x: 'Tue', y: 7 },
    { x: 'Wed', y: 5 },
  ]}
  referenceLines={[{ x: 'goal', y: 6 }]}
  barStyle={{ cornerRadius: 4 }}
  showLegend
  style={{ height: 220 }}
/>
```

When no point sets `color`, bars and pie sectors take a category color for
each `x` and the legend names them. When any point sets `color`, every mark
uses its own point's color and the rest are blue. Line, point, area, and
rectangle marks are blue unless their style or point names a color.

## Styles

A style object takes only the keys of its own type; any other key throws.
Colors take a color string or a processed color number.
