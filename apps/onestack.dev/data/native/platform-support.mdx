| Compose views | unsupported (throws) | One.Android.* | unsupported (throws) |
| EdgeFade, Blur, Mask | native primitive | native primitive | CSS gradients, backdrop-filter, alpha mask-image |

| Notifications | permission, badge, channels (no-op), events, handler, scheduling | permission, badge (no-op), channels, events, handler, scheduling | denied, inert |
| Clipboard | UIPasteboard | ClipboardManager | navigator.clipboard |

| ImagePicker | PHPickerViewController + camera | system photo picker + camera intent | file dialog + capture input |

| ScreenOrientation | scene geometry locks + listeners | display rotation locks + listeners; runtime overrides manifest | screen.orientation; unsupported locks reject |
| Share | activity sheet + completion | system chooser; completed when a target is chosen | navigator.share where present |

| AppIcon | alternate icon sets | manifest activity-alias entries | unavailable |

| LocalAuthentication | LAContext biometrics | BiometricManager + BiometricPrompt | unavailable |
| ScreenCapture | scene capture state + screenshot notifications | activity screenshot callback (34+) + window-manager recording state (35+); PixelCopy PNG capture (26+) | unavailable |

`One.iOS.ToolbarHost`, `One.iOS.MenuAction`, and the `ZoomTransition*`
components return `null` on other platforms, so they are safe to keep in
cross-platform component trees. SplitView renders its routed `slot` without
native columns on Android and web. Other SwiftUI components, including `Menu`,
`ContextMenu`, and `Toolbar`, throw outside iOS builds, and Compose components
throw outside Android builds, so keep those branches behind platform checks.

| Root service | Web behavior |
|--------------|--------------|
| FileSystem | origin-private folders and committed OPFS writes |
| Motion | observed device events; magnetometer unavailable |
| Speech | browser recognition API where present |
| Device | browser platform and Intl localization; no hardware identity |
| KeepAwake | Screen Wake Lock where present; browser release is reflected |
| ScreenOrientation | screen.orientation; unsupported locks reject |
| Share | navigator.share where present; cancellation is incomplete |
| Print | unavailable: current-document print cannot return PDF completion |
| Location | geolocation positions and foreground watches; no geocoder |
| Audio | HTMLAudioElement, MediaRecorder, optional Media Session |
| Contacts | Contact Picker where present; no address-book access or editing |

Browser capabilities depend on context and permissions. SSR preserves each
service's existing unavailable contract.
