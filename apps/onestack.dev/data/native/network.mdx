---
title: Network
description: Connection state and reachability
---

Connection state through `One.Network`. Backed by `NWPathMonitor` on iOS, `ConnectivityManager` with a `NetworkCallback` on Android, and `navigator.onLine` with `online`/`offline` events on web.

```tsx
import { One } from 'one'

const state = await One.Network.getState()
// { type: 'wifi', isConnected: true, isInternetReachable: true }

const subscription = One.Network.addStateListener((next) => {
  console.log(next.type)
})
subscription.remove()

const live = One.useNetworkState()
```

`type` is one of `none`, `unknown`, `cellular`, `wifi`, `bluetooth`, `ethernet`, `wimax`, `vpn`, or `other`. On web a live connection reports `unknown`, since browser connection types are unreliable.

The library manifest declares `ACCESS_NETWORK_STATE` (a normal install-time permission, merged into the app automatically).
