# Building this One app

- Before changing this app, read the installed `building-with-one` skill and its references for the task.
- If the skills are missing, run `npx skills add onejs/skills` from this app root and select your coding agent. For all six skills with Codex and Claude Code, run `npx skills add onejs/skills --skill '*' --agent codex claude-code --yes`.
- Start a fresh agent session after installing so the skills appear in its catalog. Use the relevant One topic skill for loaders, API routes, render modes, deployment, or recipes.
- Check examples against the installed `one` version. Newer native APIs can require an upgrade.
- Follow this app's package scripts and platform files. See https://onestack.dev/docs/agents for installation and usage guidance.
