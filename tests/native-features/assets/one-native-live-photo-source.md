# Live Photo proof media

`one-native-live-photo.jpg` and `.mov` are a paired Live Photo created for this
suite from FFmpeg's `testsrc2` generator. The pixels contain no third-party
photo or video. The still is a 320×240 JPEG from 1.5 seconds; the MOV is a
three-second H.264 clip at 30 frames per second. Both carry the same Live Photo
asset identifier `A7D73B48-C8A0-45C4-9966-52E42F571610` in Apple maker-note
and QuickTime metadata. The pair was packaged with the MIT-licensed
`Hiwoniu/live-photos` livephoto-packager at commit
`af905a3a62c81a925dbee3aef971379cb1f7a720`; no sample media from that
repository is included here.
